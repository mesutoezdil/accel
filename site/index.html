Why accel

Every view answers a question someone actually has at 2 a.m., not a dashboard to admire.

Overview

Which device is idle while a pod still holds it?

Fleet totals, per-device state, and idle-allocated devices, in one table.

Workloads

Which workload is wasting spend?

Devices held, efficiency, cost per hour, and energy per workload, from your own price list.

Kubernetes · Nodes

Which pod, and which Slurm job, owns this device?

Process → container → pod → workload, and the same for Slurm jobs, side by side.

Links

Is this device isolated on the fabric?

PCIe generation and width, NVLink counts and errors, and the topology matrix.

History

What happened 15 minutes ago?

Scrub any metric back in time, with events pinned at the cursor.

Health

Is this reading real, or a guess?

Every score explained, and every value either measured or shown as N/A, never 0.

Install

One static binary. No agent to run first, no database.

curl -fsSL -o accel https://github.com/mesutoezdil/accel/releases/latest/download/accel-linux-amd64
chmod +x accel && sudo mv accel /usr/local/bin/
brew install mesutoezdil/tap/accel
go install github.com/mesutoezdil/accel@latest
docker run --rm -p 9800:9800 --gpus all --pid=host \
  -e NVIDIA_DRIVER_CAPABILITIES=utility \
  ghcr.io/mesutoezdil/accel:latest

Then: accel --demo to explore without hardware, or accel to probe what is on the machine.
